# ТЗ. Первые роуты

### **Цель**

Целью данного проекта является практическое закрепление знаний по работе с маршрутами, телом запроса и заголовками в Express.js.

### **Задачи**

1. Создать веб-приложение, используя Express.js.
2. Разработать несколько маршрутов (роутов), обеспечивающих обработку HTTP-запросов.
3. Создание маршрутов наподобие CRUD операциям.

### **Маршруты (Роуты)**

1. Создать маршрут для обработки HTTP GET-запроса по пути **`/api/hello`**, который возвращает простое сообщение `"Привет, Redev!"`.
2. Создать маршрут для обработки HTTP POST-запроса по пути **`/api/echo`**, который принимает JSON-объект с ключом **"message"** в теле запроса и возвращает этот текст как ответ.
